# SkillBridge AI — Campus-to-Business Micro-Freelance Hub

> **Where College Digital Talent Meets Small Business Budgets.**  
> A micro-freelancing platform designed for Indian college students to build commercial portfolios while local small businesses (bakeries, salons, gyms, tutors) get affordable digital services (₹500–₹2,500).

---

## 🚀 Live Demo & Quick Start (Zero Installation)

This project is built using modern **Vanilla HTML5, CSS3, and ES6+ JavaScript**. It requires **zero installations, no Node.js, and no build steps**.

### To Run Locally:
1. Double-click `index.html` in your file explorer, or open it in any browser (Chrome, Edge, Brave, Safari).
2. The prototype loads with pre-populated sample projects, verified student profiles, and interactive escrow tracking.

## 💡 Key Features Implemented in This Prototype

1. **1-Click Live Persona Switcher:** Toggle between *Student View (Priya)* and *Business View (Sweet Delights Bakery)* in under 2 seconds.
2. **Deterministic Smart AI Match Engine:** Computes an instant match score (e.g. `96% AI Match`) based on skill overlap, budget range, and student availability.
3. **Simulated Escrow & Ledger:** Demonstrates the ₹500 $\rightarrow$ ₹450 student payout + ₹50 (10%) platform revenue model without exposing judges to test-card errors or OTP failures.
4. **GST-Ready Tax Invoice:** Generates an official printable tax invoice (`#SB-2026-0814`) with GSTIN, SAC/HSN codes, and CGST/SGST breakdown.
5. **Simulated College ID Verification (OCR):** Mock upload interface showing real-time student identity validation.
6. **Full State Persistence:** Saves applications, new project postings, and wallet earnings directly in browser `localStorage`.
7. **Interactive Platform Revenue Calculator:** Live slider demonstrating economics from ₹300 to ₹5,000.

## 🌐 How to Host 100% Free Forever

### Option A: Netlify Drop (Takes 30 Seconds — No Git Needed)
1. Open [app.netlify.com/drop](https://app.netlify.com/drop) in your browser.
2. Drag and drop this entire folder (`startup`).
3. You will immediately receive a public live URL (e.g. `https://skillbridge-ai.netlify.app`).

### Option B: GitHub Pages
1. Push this folder to your repository: `https://github.com/Aravkataria/NAVDRISHTI`.
2. Go to your repo **Settings** > **Pages**.
3. Under **Branch**, select `main` and root `/`, then click **Save**.
4. Your site is live at: `https://aravkataria.github.io/NAVDRISHTI/`.
